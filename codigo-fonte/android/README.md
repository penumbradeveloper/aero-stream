# Android (APK) — Fase 3C

Esta pasta é reservada para o APK. Por enquanto:

- O Android **já funciona** pelo navegador Chrome: abra o endereço do servidor > menu > **Instalar app** (vira um ícone).
  Dá para assistir, conversar e usar tudo. **Compartilhar a tela do celular** exige o APK nativo.
- Na Fase 3C o APK será gerado com o Capacitor usando a mesma pasta `app/`, mais um módulo nativo (Kotlin) para:
  compartilhar a tela e o som do celular, e receber o controle remoto de PC (gestos).
